# BÀI TẬP LỚP - QUẢN LÝ NHÂN VIÊN

## 1. Thông tin bài tập

- **Môn học:** Lập trình trên Windows
- **Ngày thực hiện:** 16/09/2026
- **Chủ đề:** Quản lý nhân viên bằng C#
- **Ngôn ngữ:** C#
- **Loại ứng dụng:** Console Application

## 2. Mục tiêu

- Vận dụng kiến thức lập trình hướng đối tượng trong C#.
- Xây dựng các lớp quản lý nhân viên.
- Áp dụng tính kế thừa trong chương trình.
- Phân loại nhân viên theo từng nhóm công việc.
- Thực hành tổ chức mã nguồn thành nhiều lớp.

## 3. Các lớp trong chương trình

| Tệp | Chức năng |
|---|---|
| `NhanVien.cs` | Lớp nhân viên cơ sở |
| `NhanVienVanPhong.cs` | Lớp nhân viên văn phòng |
| `NhanVienKinhDoanh.cs` | Lớp nhân viên kinh doanh |
| `NhanVienThoiVu.cs` | Lớp nhân viên thời vụ |
| `Program.cs` | Chứa phương thức Main và điều khiển chương trình |

## 4. Kiến thức áp dụng

- Lập trình hướng đối tượng.
- Xây dựng lớp và đối tượng.
- Tính kế thừa.
- Phương thức khởi tạo.
- Phân loại đối tượng theo nghiệp vụ.
- Nhập và xuất dữ liệu trên Console.
